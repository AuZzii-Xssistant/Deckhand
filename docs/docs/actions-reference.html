    Actions reference

    Every action, its options and what Undo can reverse.

    Actions run in order for each matching file. Names in code are the ones used in the draft JSON format.

    The screenshot shows the two actions of the rule Release builds: Run saved script (run_script) with the script Sign release, then Copy file (copy) to a network folder.

    Files and folders

    ActionOptionsUndo
    moveDestination (created if needed; relative means relative to the file's folder), if the name is taken, mirror subfolders, remove empty folders, if a value is missingYes
    copySame as move, plus later actions use the copyYes
    renameNew name without the extension, if taken, if a value is missingYes
    change_extNew extensionYes (as a rename)
    sortBase folder (empty means the file's own folder), sort by type, extension, year, month or dayYes
    recycleRemove empty foldersYes, from the Recycle Bin
    deleteRemove empty folders. Permanent.No
    remove_empty_folderWhich folder (where the file started, or where it is now), and also empty parentsYes

    Move and copy keep the file name. Sort uses the file's modified date for year, month and day.

    Archives

    ActionOptionsNotes
    extractDestination (empty means a new folder next to the archive), delete the archive afterwardsHandles zip, 7z, rar, tar and tar.gz. Never overwrites.
    zipZip file, if taken, keep structureAdds the file to a .zip. The original stays.

    Undo reverses zip and extract. A zip never adds itself.

    Commands and messages

    ActionOptionsNotes
    runCommand, shell (default, cmd, PowerShell, pwsh), run elevated, time-outStdout and stderr appear in History. Exit code 0 means done. Time-out default is 10 minutes.
    run_scriptA saved script and its argumentsScripts are managed on the Scripts page.
    logMessageWrites to the log. Good for dry-running an idea.
    notifyMessageShows a message.

    A saved script has a shell, a body, arguments and a time-out. The screenshot is the script Sign release that the rule above uses: a PowerShell script that signs the installer and writes its checksum, run with the file path as its argument and stopped after 300 seconds.

    Values from {variables} are made safe before they are inserted into a command. Run elevated needs Deckhand to be started as administrator. It never prompts. Undo does not cover what a command or script did.

    Name conflicts

    SettingChoices
    If the name is taken (on_conflict)rename (adds _2, _3), skip, overwrite (the old file goes to the Recycle Bin)
    If a value is missing (on_missing)fail, skip, fallback

    See Actions and conflicts for the safety rules about skipped steps.
