    Command line

    Run presets and rules without opening the window, and check AI-written drafts.

    Deckhand can run a preset or rule without opening its window. Runs started this way appear in History with the source cli.

    The Command line card in Settings (screenshot) shows the usage and the exit codes of the version you have installed.

    Note

    The complete list of options and exit codes is shown in the app under Settings → Command line, which always matches the version you have installed.

    Run a rule or a preset

    CommandWhat it does
    Deckhand.exe --run-rule "<name or id>"Runs a saved rule once on its own watch folders. It does not need to be switched on.
    Deckhand.exe --run-preset "<name or id>" --folder "<path>"Runs a preset on one folder.

    Without --yes (or with --dry-run) only the preview is printed and nothing is changed. Add --yes for a real run and --json for output a program can read.

    Prefer the id. Names are not unique: two rules can share one name. A name can be used when it is unique, but an id always finds exactly one rule or preset. A script or an AI client should use the id, which --list-presets --json and the MCP rule list return.

    Exit codes

    CodeMeaning
    0Everything went well, or the preview found nothing that would fail.
    1The run finished but some steps failed, or the preview says some would fail.
    2Usage error: unknown option, missing value or missing --folder. Nothing was done.
    3Not found: no such preset, rule or folder.
    4A real run was asked for without --yes. Nothing was changed; the preview was printed.
    5Internal error, for example the run finished but could not be written to the history.
    6Ambiguous: several rules or presets have that name. Nothing was done. Run it again with the id.

    With --json, exit code 6 prints an error object with "ambiguous": true and a candidates list. Each candidate has its id, name, group and more, so a script can pick the right one and run the same command with that id:

    {"schema":1,"mode":"error","exit_code":6,"error":"...","ambiguous":true,"candidates":[{"id":"r_inv","name":"Invoices to Documents","group":"Documents",...}]}

    Where to find the options

    1. Open Deckhand and go to Settings.
    2. Find the Command line card. It lists every option and exit code for your version.

    Authoring helpers

    These options help an AI tool or script that writes rule drafts. They validate and print information. They never import or run anything.

    CommandWhat it does
    Deckhand.exe --authoring-schemaPrints the JSON schema for rule drafts.
    Deckhand.exe --authoring-catalogueLists IDs you can reuse in a draft.
    Deckhand.exe --validate-draft draft.jsonChecks a draft and reports structured errors.
    Deckhand.exe --validate-draft draft.json --example "C:\full\file.ext"Also simulates the draft against a synthetic example file.
    .\Deckhand.exe --validate-draft .\draft.json

    The schema is also published as deckhand-draft.schema.json.
