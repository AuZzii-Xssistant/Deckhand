    Overview

    What Deckhand does and where to start.

    Deckhand is a Windows file organiser. You give it a folder and a rule. It finds the files that match, shows you what would happen, and then moves, renames, sorts, copies, zips or extracts them. It can run once, watch a folder for new files, or follow a schedule.

    The Home page is the first thing you see. It has counters for the files handled, a box that runs a preset on a folder, the rules that need attention and your latest runs.

    The Rules page lists every rule in groups, in run order, with the actions, the watched folders and a live status.

    The idea in four steps

    1. Pick a folder to watch, such as your Downloads.
    2. Say which files with conditions: name, type, dates, size, metadata or contents.
    3. Say what happens with actions: move, rename, sort into folders, copy, zip, extract, recycle and more.
    4. Preview, then run. Nothing changes until you press Run, and most runs can be undone from History.

    Note

    Deckhand is in beta. Keep backups of important files, especially before trying rules that delete or overwrite.

    What you will see in the app

    The sidebar in Deckhand has pages for the things you do most. This documentation uses these names.

    PageWhat it is for
    HomeA quick look at what is running and your recent runs.
    RulesRules that watch folders and handle matching files.
    PresetsSaved tidy-ups you run on a folder you choose.
    SchedulesEverything that runs by itself at a set time.
    HistoryEvery run and every action, with Undo, plus a searchable Log.
    SimulateFollow an example file through your rules without changing anything.
    DiagnosticsWhat Deckhand costs in CPU and memory, and how long each rule takes.
    SettingsAppearance, safety defaults, the OCR language, backup, the Explorer menu, AI integrations and the link to this documentation. See Settings.

    The exact list and order can differ between releases. If a page here does not match what you see, check the in-app Help.
