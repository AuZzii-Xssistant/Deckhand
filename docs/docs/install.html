    Install

    Requirements and the two ways to get Deckhand on Windows.

    Deckhand runs on 64-bit Windows 10 and 11. It needs the Microsoft Edge WebView2 Runtime, which is already present on most up-to-date PCs.

    Requirements

    • 64-bit Windows 10 or 11.
    • Microsoft Edge WebView2 Runtime. If it is missing, install the Evergreen Runtime from the WebView2 download page.

    Choose how to install

    OptionBest forUpdates
    Microsoft StoreMost people. The signed version.Automatic
    GitHub release (portable EXE)A free portable build you keep in a folder of your choice.Manual: download the new EXE

    Microsoft Store

    1. Open the Deckhand page in the Microsoft Store.
    2. Select Get and wait for the install to finish.
    3. Open Deckhand from the Start menu.

    Portable EXE from GitHub

    1. Open the latest release and download Deckhand.exe.
    2. Download the SHA-256 checksum from the same release and compare it with your file (see below).
    3. Move Deckhand.exe to a folder you intend to keep, then run it.

    Warning

    The portable executable is unsigned. Windows SmartScreen may show an unknown-publisher or unrecognised-app warning. Verify the download against the release checksum before you decide whether to run it.

    To check the file in PowerShell, run this in the folder that holds the download and compare the result with the published checksum:

    Get-FileHash .\Deckhand.exe -Algorithm SHA256

    If the search finds nothing, use the Store or the GitHub release.

    First launch

    1. Open Deckhand. It starts on Home.
    2. Do not point a new rule at an important folder yet. Make a test folder with a few sample files.
    3. Continue with Your first rule.

    On a first start Deckhand shows the Home page with nothing watching yet, as in the screenshot: the counters are at zero and the lists say No rules yet and No runs yet. Shortcuts offer Juggle now, New rule and the Command palette, and the Run a preset box works straight away.

    The Rules page of a fresh install says No rules yet and offers Add rule and New group.

    Help is built in. The book button in the title bar, Open the docs in Settings and Online docs on the Help page all open this documentation in your browser. See Settings.

    Updating

    • Store: updates arrive automatically.
    • Portable EXE: download the new Deckhand.exe from the releases page and replace the old one. Back up your library first from Settings → Backup if you want a safety copy.
