    Keyboard shortcuts

    Shortcuts for moving around Deckhand, editing rules and working with lists.

    Deckhand is built to be used from the keyboard. Ctrl+K opens the command palette. It searches pages, actions, rules and your files. In the screenshot the word rule is typed, and the palette lists Go to Rules (with its shortcut Ctrl+3), New rule and Open rule entries for the saved rules.

    Everywhere

    ShortcutAction
    Ctrl+1 to Ctrl+9Open the first nine pages in sidebar order. Help and Settings have no number.
    Ctrl+KOpen the command palette. It also searches your files.
    EscClose the top menu or window first, then go back.
    Tab and Shift+TabMove between controls. They stay inside an open window.

    In the rule editor

    ShortcutAction
    Ctrl+EnterPreview
    Ctrl+SSave

    In lists

    ShortcutAction
    TabReach the list
    Up and Down, Home, EndMove between items
    Enter or SpaceOpen the focused item
    Shift+F10 or the context-menu keyOpen the row menu

    On the Rules page

    ShortcutAction
    Ctrl+ASelect every shown rule
    Ctrl+SpaceToggle one rule
    Shift+Up and Shift+DownExtend the selection
    Alt+Up and Alt+DownMove the focused rule one place in the run order
    Ctrl+click, Shift+clickToggle a rule, or select a range
