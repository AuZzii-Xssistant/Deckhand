    MCP troubleshooting and FAQ

    Fixes for an AI client that cannot connect to Deckhand, missing tools, Windows path problems and common questions.

    The client does not connect

    • Make sure the client was fully restarted after you edited its configuration.
    • Check that command points at a file that exists. Paste the path into the Windows Run box or open it in Explorer.
    • If you moved a portable Deckhand.exe, the old path in the entry is dead. Open Connect an AI client... again and paste the new entry.
    • Run the program yourself in PowerShell: & "C:\Users\ScriptKiddyMonkey\AppData\Local\Deckhand\Deckhand.exe" --mcp. It waits silently for input, which is normal. Press Ctrl+C to leave.
    • Wrong arguments print Use --mcp, optionally followed by --data <existing absolute profile path> [--rule-edits]. and end with exit code 2. --data must be an absolute path to a folder that exists, and --rule-edits must come right after it.
    • Security software can block a program that a client starts. Allow Deckhand.exe.

    Tools are missing

    • You only see the four authoring tools: the entry has no --data. The setup window adds it when Use the library currently open in Deckhand is ticked.
    • You see five tools: the entry has --data but not --rule-edits. With library access you should see eleven.
    • The client caches its tool list. Restart the client or start a new chat.
    • deckhand_list_editable_rules returns an empty list: only rules that are switched off and have no command or script action are listed. A rule you switched on is not visible.

    Windows path and quote problems

    • JSON and TOML: write each backslash twice. "C:\\Users\\ScriptKiddyMonkey\\AppData\\Local\\Deckhand\\Deckhand.exe".
    • On a command line (for example claude mcp add), quote paths that contain spaces and write single backslashes.
    • Keep every path in args as its own list item. Do not put the whole line into command.
    • Use the full path, not just Deckhand.exe: a client may not search your PATH.
    • On a command line do not end a quoted path with a lone backslash before the closing quote ("C:\Folder\").

    Version mismatch

    The entry points at one Deckhand.exe, and that is the version the tools come from. If you update Deckhand to a new place or version and keep an old entry, the client talks to the old program. After an update or a move, copy a fresh entry from Connect an AI client.... In View AI reference..., the MCP tools tab lists the tools of the version you have installed.

    A tool call comes back as an error

    Failed calls are normal tool results marked as errors, usually with a hint. Typical ones:

    • Invalid arguments for ...: the assistant sent a wrong or extra argument. It should read the tool's schema and call again.
    • No such editable rule: the rule is gone, switched on, or has a command or script. List the rules again.
    • -32602 ... deckhand_submit_rule is only offered when Deckhand is started with --data: the entry has no --data. Copy a fresh entry with the library box ticked, or use deckhand_prepare_draft.
    • Unknown argument ... or limit must be between 1 and 200: a list tool got an argument it does not have or a value out of range.
    • The work result file could not be understood: the app wrote progress this server version does not know. The decision is still correct; check the progress in Deckhand.
    • -32002 Server not initialized: the client sent a request before finishing the MCP handshake. This is a client problem; restart the client.

    A request shows an error such as "The saved rule changed"

    The rule was changed after the assistant read it. Ask the assistant to read the rule again and propose the edit again.

    "Review AI requests" shows nothing

    The request may have been discarded or may not have reached the profile that is open. With --data, the profile folder in the entry must be the one Deckhand is using now. If you use more than one profile or a portable copy, check the folder.

    The rule I submitted did not appear

    Queued rules arrive when the running app reads its inbox, which happens within a few seconds while the app is open. If Deckhand is closed, open it. If the draft was invalid when the app read it, it is set aside and never added.

    FAQ

    Does the AI see my files? No. The connection has no tool that reads, lists or searches files. See Safety model.

    Can the AI run a rule? No. It can ask you to open a preview. A run happens only if you confirm it in Deckhand.

    Why is a rule I know about missing from the list? Only rules that are off and without a command or script are visible to the client.

    Can it write rules with scripts or Run command? It can draft them for you to import by hand, but it cannot submit or edit such rules through the connection.

    Do I need an account or internet for Deckhand's part? No. Your client may need both for its model.

    Is ChatGPT supported? Not on the web. It needs a remote MCP server, and Deckhand only offers a local program.

    Does it work in the Store edition? Only if the installation has the deckhand-store.exe alias. If it does not, the setup window tells you.

    Can I turn it off? Remove the deckhand entry from the client. Deckhand has no always-running MCP service.
