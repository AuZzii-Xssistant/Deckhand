    Privacy

    A short summary of how Deckhand handles your files and data, with a link to the full policy.

    The full text is the Deckhand privacy policy. This page is a summary, not a replacement.

    In short

    • Deckhand processes your files on your device. It may read names, paths, metadata and contents, depending on your rules.
    • It does not require an account, send telemetry, or upload your files, file contents or logs to the publisher.
    • Settings, rules, history, logs and recovery data are stored locally. History and logs can contain file names and paths. Anyone with access to the data folder can read them.
    • You choose which folders Deckhand processes. You can disable rules, choose per File contents condition whether pictures and scans are read with OCR, and set how long history is kept.

    Things you add

    • Cloud folders: if you enable online-only downloads, Deckhand can request files through your sync provider, such as OneDrive. Your provider's policy applies to what it syncs.
    • Commands and scripts: a command or script you configure can do whatever it is written to do, with the permissions it runs with. Review scripts before enabling them.
    • AI clients: if you connect a client and give it library access, it can read eligible rule definitions, which can contain folder paths. The client may share what it reads with its model provider. You can connect without library access.

    Questions

    Use the support page. GitHub issues are public, so leave out personal paths and names.
